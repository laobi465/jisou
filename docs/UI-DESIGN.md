# jisou 聚合搜索引擎 UI 设计文档

> 版本：0.1.0 ｜ 生成依据：web-project-flow /bui (references/03-ui-design-rules.md)
> 适用范围：用户前台（搜索 / 解析 / 社区）+ 超管后台

---

## 一、设计风格定位

现代简约风格，干净、专业、易用。整体明亮，信息密度适中，搜索为中心。

---

## 二、严格禁用项

1. 禁止使用任何 emoji、表情符号、图标化装饰元素（图标统一使用线性 SVG icon set）
2. 禁止夸张设计：大渐变、强对比、炫光、霓虹、3D 凸起
3. 禁止毛玻璃效果：不使用 backdrop-filter、玻璃拟态、半透明模糊背景
4. 禁止暗黑风格：不使用黑色 / 深灰 / 深紫色为主的深色主题，整体保持明亮
5. 禁止过度装饰：去掉不必要的装饰线条、背景纹理、花哨图案

## 五、组件规范

### 按钮

- 圆角：6px
- 高度：主按钮 40px，次按钮 32px
- 主按钮：背景主色 `#1E5BB8`，白色文字，hover `#174A99`，无阴影或极淡阴影 `0 1px 2px rgba(30,91,184,0.1)`
- 次按钮：白色背景，主色边框 1px，主色文字
- 危险按钮：背景 `#C53030`，白色文字
- 禁用态：背景 `#E2E8F0`，文字 `#A0AEC0`，cursor not-allowed
- 不使用渐变、不使用发光

### 卡片

- 白色背景 `#FFFFFF`
- 边框 1px `#E2E8F0`
- 圆角 8px
- 内边距 16px / 20px / 24px（按密度）
- 阴影（hover 时）：`0 2px 8px rgba(0,0,0,0.04)`
- 默认无阴影

### 输入框

- 高度 40px
- 边框 1px `#E2E8F0`
- 圆角 6px
- 聚焦：边框主色 `#1E5BB8`，外发光 `0 0 0 3px rgba(30,91,184,0.12)`
- placeholder：`#A0AEC0`
- 不使用下划线样式

### 导航

- 顶部导航：白底，底部 1px 分割线 `#E2E8F0`，高度 56px
- 选中态：文字主色 + 字重 500，底部 2px 主色指示条
- hover：文字色变 `#174A99`，无背景变化

### 标签 Tag

- 圆角 4px
- 高度 22px
- 内边距 0 8px
- 字号 12px
- 来源 tag：浅色背景（主色 12% 透明度）+ 主色文字

### 表格

- 表头：浅灰背景 `#F7F9FC`，字重 500
- 行高 48px
- 行分割线 1px `#E2E8F0`
- hover 行：背景 `#F7F9FC`

## 七、动效与交互

- 过渡：`transition: all 0.18s ease`
- 加载：骨架屏（灰色块 `#E2E8F0` 闪动），不使用 spinner 居中弹层
- 搜索结果出现：`opacity 0 -> 1`，`translateY 8px -> 0`，时长 0.2s
- 不使用炫技动画、不使用视差、不使用大幅位移

## 八、页面清单与功能

### 前台页面

#### 1. 首页 / 搜索页 `/`

- 顶部：Logo + 搜索框（居中大尺寸，高度 56px）+ 来源筛选下拉
- 搜索框下方：热门搜索词（12 个，文字链，灰度递减）
- 空状态：极简引导文案 + 4 个分类入口（网盘 / TG / 文档 / 影视）
- 搜索结果态：搜索框收起至顶部，下方结果列表

#### 2. 搜索结果页 `/search?q=&source=`

- 左侧：来源筛选侧栏（网盘多选 + TG + 时间范围 + 文件大小 + 状态）
- 主区：结果卡片列表
  - 卡片内容：标题（链入详情）/ 来源 tag / 大小 / 抓取时间 / 失效标识 / 操作按钮（打开原链接、解析、收藏、举报）
  - 每页 20 条，分页器底部
- 顶部：结果统计 "共 N 条结果，耗时 X.Xs"
- 无结果：明确文案 + 建议搜索词

#### 3. 资源详情页 `/resource/:hash`

- 头部：标题 + 来源 + 大小 + 抓取时间 + 最后检测时间 + 状态徽章
- 文件列表表格：文件名 / 大小 / 类型
- 操作区：打开原链接 / 解析下载（如该来源支持）/ 收藏 / 分享 / 举报
- 下方：相关资源卡片（同关键词）
- 失效资源：顶部琥珀色提示条

#### 4. 用户中心 `/user`

- Tab：收藏 / 历史 / 我的举报
- 列表式展示，操作列含取消收藏 / 删除历史

#### 5. 登录 / 注册 `/login` `/register`

- 单卡片居中，宽度 400px
- 表单：邮箱 + 密码 + 验证码
- 第三方登录入口（按需）

### 超管后台页面 `/admin`

#### 1. 仪表盘 `/admin`

- 顶部 4 个统计卡片：资源总量 / 今日新增 / 各 Provider 调用量 / 失效率
- 折线图：最近 7 天抓取量
- 饼图：各来源占比
- 表格：最近 10 条爬虫日志

#### 2. Provider 管理 `/admin/providers`

- 表格：名称 / 类型 / 状态（启用停用）/ 调用量 / 健康状态 / 操作
- 操作：编辑配置 / 测试连接 / 启用停用 / 查看日志

#### 3. 爬虫管理 `/admin/crawl`

- 表格：任务名 / 来源 / 调度周期 / 速率 / 游标 / 状态 / 上次执行 / 操作
- 操作：立即执行 / 暂停 / 编辑 / 查看日志

#### 4. 资源审核 `/admin/resources`

- 表格：标题 / 来源 / 抓取时间 / 状态 / 举报数 / 操作
- 操作：查看 / 隐藏 / 删除 / 加入黑名单

#### 5. 黑名单管理 `/admin/blacklist`

- 类型：关键词 / URL / hash
- 表格 + 新增表单

#### 6. 用户管理 `/admin/users`

- 表格：用户 / 角色 / 注册时间 / 状态 / 操作

#### 7. 系统设置 `/admin/settings`

- 表单分组：站点配置 / 邮件配置 / 解析模块开关 / 限流配置
- 所有可变值均从配置项读取，UI 仅展示表单

## 十、文案规范

- 所有按钮、菜单、表单标签必须使用真实业务文案，禁止 Lorem Ipsum / 示例文字 / XXX 占位
- 空状态文案明确说明操作指引，如 "未找到相关资源，试试更换关键词或扩大来源范围"
- 错误文案必须可操作，如 "解析失败，请稍后重试或直接打开原链接"
- 加载态使用骨架屏，文案 "加载中..." 仅在骨架屏不适用时使用

---

## 十一、可访问性

- 所有可交互元素键盘可达，focus 样式：主色 2px outline
- 颜色对比度：正文文字对背景 >= 4.5:1
- 表单字段必须有 label，不依赖 placeholder 替代
- 图标按钮必须有 aria-label

---
